'@qbit/wallet-background': patch
---

A website's `signPsbts` of different PSBTs that each need new P2MR signatures now signs in full, in whatever order the user signs its entries (#152). The approval opens one signature batch for its prepared entries (`WalletController.openQbitProviderSignatureBatch`, which resolves with the batch's id) and marks each with `qbitSignatureBatch` (`id`, `index` and the whole batch's `budget`); `signPsbtV2` signs an entry as a member of that batch. The request records the id as `qbitSignatureBatchIds`, and closes that batch, and only that one, once it is answered (`releaseQbitSignatureBatches(batchIds)`) or once it fails: rejected, its window closed, its page gone, its payload changed, or refused while another approval was pending. Ids in the page's own parameters are never closed. A `signPsbts` arriving while another approval is pending is refused before its PSBTs are prepared, so while the user signs one request, a burst of others opens no batches. With nothing pending, a burst still opens up to 64 website batches: one request is shown, and the rest are refused as already pending or with "Too many signing requests are waiting". Website batches are never evicted while their request is open, so such a burst cannot close the batch of the request being signed. A lock ends any pending `signPsbts` approval whose batch it closed, with 4001 "The wallet locked before this batch was signed; send the request again", and a request whose batch a lock closed before its approval showed is refused with the same error. This replaces the `qbitApprovedBatchDuplicate` mark, so duplicated PSBTs sign through the same batch. `analyzeLocalPsbts` opens the batch of a local batch of two or more P2MR PSBTs this wallet signs, each with its approved budget, reopening the same batch only on a review of the same bytes with the same budgets (as before a quick-sign), and returns it as `signatureBatch`, so its entries also sign in full through `signLocalBatchPsbt` or one at a time. A batch whose total exceeds the remaining signatures is refused before approval.
