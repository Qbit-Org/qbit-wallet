Add what a wallet reset needs. `BUS_METHODS.WALLET_RESET` (`walletReset`) is the message every open wallet page receives once `WalletController.resetWallet` has erased the wallets. `ErrorCodes.WALLET_RESET_INCOMPLETE` (-19), with the message key `wallet_reset_incomplete`, is the rejection for a reset that erased the wallets and the password but could not clear some of the other stored wallet data; apart from it and `WALLET_RESET_OUTCOME_UNKNOWN`, a rejection from `resetWallet` means nothing was erased. `QbitResetWalletOptions` is the reset's options type: the recovery-risk acknowledgement `QbitRemoveKeyringOptions` carries for a single removal, plus `lastWalletKey`, the wallet whose removal led to the reset. `ErrorCodes.WALLET_RESET_NOT_LAST_WALLET` (-20), with the message key `wallet_reset_not_last_wallet`, is the rejection for a reset asked for with `lastWalletKey` when that wallet is gone or another usable wallet exists; nothing is erased. `ErrorCodes.WALLET_RESET_OUTCOME_UNKNOWN` (-21), with the message key `wallet_reset_outcome_unknown`, is the rejection for a reset that could not tell whether the wallets were erased, because storage failed while the keys were being erased. `ErrorCodes.WALLET_PAGE_OUT_OF_DATE` (-22), with the message key `wallet_page_out_of_date`, is the refusal for a wallet page's request that names a wallet which is no longer the one set up.
